# Control-Room TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Textual terminal app, `python -m matchcut.tui footage.mp4`, that drives and watches pipeline runs with live events, blocking checkpoints you can continue/redo/abort with a note, five views (Run, Shots, Story, Cut, Config) with real frames in the terminal, and read-only inspection of past workspaces.

**Architecture:** `matchcut/tui/` depends on `matchcut/pipeline/` (plan 1's events, checkpoints and cancel) and never the reverse. `PipelineBridge` runs `Pipeline.run()` on a plain daemon thread, forwards events through a `queue.Queue`, and answers checkpoints from the UI thread; it is framework-free and tested without Textual. `RunState` is the single UI-side model: stage statuses, event log, usage totals, and mtime-cached readers for the workspace files. `MatchcutApp` pumps the queue on a 50 ms timer, applies events to `RunState`, and asks each view to refresh from it. Images come from the workspace's cached frames via `textual-image` (auto protocol, half-block fallback; forced half-block under the headless test pilot).

**Tech Stack:** Python 3.9+, Textual 8.x, textual-image, Pillow, pytest with `pytest-textual-snapshot`; the existing mock backend and synthetic footage for tests.

**Spec:** `docs/superpowers/specs/2026-10-16-tui-design.md` (sections Architecture: TUI package and Threading model, Screens, Data flow and state, Error handling, Testing: TUI side, Dependencies and files). Plan 1 (`docs/superpowers/plans/2026-10-16-pipeline-events-checkpoints.md`) delivered the pipeline side; the final review of plan 1 added four requirements folded in here: the bridge must not re-emit `Checkpoint` (the pipeline already does), `S` during a pending checkpoint must also answer it (`Abort`), config edits reach a redo only through the live `PipelineConfig` object the pipeline holds (and are re-saved on run/redo), and a `descriptions.json` edit must also update the in-memory context for a redo in the same run.

## Global Constraints

- TUI code lives in `matchcut/tui/`; tests in `tests/tui/` (new package; `tests/__init__.py` already exists). Run TUI tests with `python3 -m pytest tests/tui -q`; the pipeline suite `python3 -m pytest tests/pipeline -q` (68 pass) must keep passing and must not import `textual`.
- Python 3.9 compatible syntax: every module starts with `from __future__ import annotations`; `Optional[...]`, `List[...]`, `Dict[...]`, `Deque[...]`, `Callable[...]` from `typing`, never `X | None` at runtime.

- Stage names are the pipeline's: `ingest`, `describe`, `narrative`, `roughcut`, `pass:<name>`, `render`, `report`. Checkpoint answers are `matchcut.pipeline.events.Continue/Redo/Abort`.
- The bridge never emits `Checkpoint` events itself; the pipeline's `_ask` already does.
- All event handling that touches widgets runs on the Textual UI thread; the pipeline thread only puts events on the queue and blocks in the checkpoint handler.
- No view may crash on a missing workspace file; show an empty state instead.

```python
from __future__ import annotations

import asyncio
import shutil
from pathlib import Path
from typing import Callable

import pytest

from matchcut.pipeline.config import PipelineConfig
from matchcut.pipeline.demo import make_demo_footage
from matchcut.pipeline.pipeline import Pipeline


def run_async(coro):
    """Run an async test body without pytest-asyncio (Textual's run_test is async)."""
    return asyncio.run(coro)


@pytest.fixture(scope="session")
def demo_video(tmp_path_factory) -> Path:
    if shutil.which("ffmpeg") is None:
        pytest.skip("ffmpeg not installed")
    return make_demo_footage(tmp_path_factory.mktemp("footage") / "demo.mp4")


@pytest.fixture(scope="session")
def mock_workspace(demo_video, tmp_path_factory) -> Path:
    """A workspace with every stage output from a full mock run (no render)."""
    ws = tmp_path_factory.mktemp("ws")
    cfg = PipelineConfig(source=str(demo_video), workspace=str(ws), target_duration=8.0)
    cfg.llm.backend = "mock"
    cfg.render.enabled = False
    Pipeline(cfg).run()
    return ws


async def wait_for(pilot, predicate: Callable[[], bool], timeout: float = 90.0) -> None:
    """Pause the pilot until ``predicate()`` is true."""
    loop = asyncio.get_event_loop()
    deadline = loop.time() + timeout
    while not predicate():
        if loop.time() > deadline:
            raise TimeoutError("condition not met in time")
        await pilot.pause(0.1)
```

```python
from pathlib import Path

from matchcut.pipeline import events
from matchcut.pipeline.config import PipelineConfig
from matchcut.tui.state import PRICES, RunState, StageStatus


def test_stage_names_follow_the_config(mock_workspace):
    cfg = PipelineConfig.load(mock_workspace / "config.json")
    st = RunState(cfg)
    assert st.stage_names() == ["ingest", "describe", "narrative", "roughcut"] + [f"pass:{p}" for p in cfg.passes] + ["render", "report"]
    assert all(isinstance(s, StageStatus) and s.state == "pending" for s in st.stages.values())
    assert st.run_status == "idle" and st.checkpoint is None


def test_apply_events_drives_statuses_and_usage(mock_workspace):
    cfg = PipelineConfig.load(mock_workspace / "config.json")
    st = RunState(cfg)
    st.apply(events.RunStarted(source=cfg.source, workspace=str(mock_workspace), config={}))
    assert st.run_status == "running" and st.started_at is not None
    st.apply(events.StageCached(stage="ingest", path="x/shots.json"))
    st.apply(events.StageStarted(stage="describe"))
    assert st.stages["ingest"].state == "cached" and st.stages["describe"].state == "running"
    st.apply(events.ModelCall(name="describe", images=1, seconds=1.0, input_tokens=1000, output_tokens=200, model="m"))
    assert st.calls == 1 and st.input_tokens == 1000 and st.output_tokens == 200 and st.model == "m"
    st.apply(events.StageFinished(stage="describe", seconds=2.5, path="x/descriptions.json"))
    assert st.stages["describe"].state == "done" and st.stages["describe"].seconds == 2.5
    st.apply(events.Checkpoint(stage="describe", summary={"shots": 8}))
    assert st.run_status == "waiting" and st.checkpoint.stage == "describe" and st.stages["describe"].state == "waiting"
    st.resolve_checkpoint()
    assert st.checkpoint is None and st.run_status == "running" and st.stages["describe"].state == "done"
    st.apply(events.StageStarted(stage="pass:boom"))  # unknown stage names are tolerated
    st.apply(events.RunFailed(stage="pass:boom", error="kaboom", traceback="tb"))
    assert st.run_status == "failed" and st.stages["pass:boom"].state == "failed" and st.last_error == "kaboom"
    assert len(st.events) == 7


def test_run_finished_and_cost(mock_workspace):
    cfg = PipelineConfig.load(mock_workspace / "config.json")
    st = RunState(cfg)
    st.apply(events.RunStarted(source="", workspace="", config={}))
    st.apply(events.ModelCall(name="x", images=0, seconds=0, input_tokens=1_000_000, output_tokens=100_000, model="claude-opus-5-5"))
    inp, out = PRICES["claude-opus-5-5"]
    assert abs(st.cost_estimate() - (inp + out * 0.1)) < 1e-9
    st.apply(events.RunFinished(final_path="f", render_path="", report_path="r", seconds=12.0))
    assert st.run_status == "finished" and st.finished_at is not None and st.elapsed() >= 0
    st.apply(events.ModelCall(name="x", images=0, seconds=0, input_tokens=1, output_tokens=1, model="unknown-model"))
    assert st.cost_estimate() >= inp + out * 0.1  # unknown models add nothing but never raise


def test_workspace_readers(mock_workspace):
    cfg = PipelineConfig.load(mock_workspace / "config.json")
    st = RunState(cfg)
    assert st.media() is not None and st.media().fps == 25.0
    assert len(st.shots()) == 8
    assert set(st.descriptions()) == {s.index for s in st.shots()}
    assert st.narrative()["beats"]
    assert st.music() is None
    stages = st.timeline_stages()
    assert stages[0] == "roughcut" and stages[-1] == "final" and "matchcut" in stages
    final = st.timeline("final")
    assert final is not None and final.clips
    assert st.timeline("nope") is None
    cid = final.clips[0].id
    assert isinstance(st.decisions_for(cid, "final"), list)


def test_readers_tolerate_an_empty_workspace(tmp_path):
    cfg = PipelineConfig(source="missing.mp4", workspace=str(tmp_path / "empty"))
    st = RunState(cfg)
    assert st.media() is None and st.shots() == [] and st.descriptions() == {} and st.narrative() == {}
    assert st.music() is None and st.timeline_stages() == [] and st.timeline("final") is None


def test_readers_reload_when_the_file_changes(mock_workspace):
    cfg = PipelineConfig.load(mock_workspace / "config.json")
    st = RunState(cfg)
    before = st.narrative()["logline"]
    path = mock_workspace / "narrative.json"
    data = path.read_text().replace(before, "A changed logline")
    import os, time
    path.write_text(data)
    os.utime(path, (time.time() + 5, time.time() + 5))  # guarantee a new mtime
    st.invalidate(str(path))
    assert st.narrative()["logline"] == "A changed logline"
    path.write_text(data.replace("A changed logline", before))
    os.utime(path, (time.time() + 10, time.time() + 10))
    assert st.narrative()["logline"] == before  # mtime change alone is enough, no invalidate needed
```

```python
"""Launcher: parse arguments, build the config, guard the optional dependencies, run the app."""
from __future__ import annotations

import argparse
import sys
from pathlib import Path
from typing import List, Optional

from matchcut.pipeline.config import PipelineConfig

INSTALL_HINT = "The TUI needs textual and textual-image: pip install -r requirements-tui.txt"


def parse_args(argv: Optional[List[str]] = None) -> argparse.Namespace:
    p = argparse.ArgumentParser(prog="matchcut.tui", description="Control room for the editing pipeline")
    p.add_argument("source", nargs="?", default=None, help="footage to edit (omit to open an existing --workspace read-only)")
    p.add_argument("-w", "--workspace", default=None, help="working directory (default: <source>_edit/)")
    p.add_argument("-b", "--brief", default="", help="creative direction for the model")
    p.add_argument("-t", "--target-duration", type=float, default=None)
    p.add_argument("--backend", choices=["anthropic", "mock"], default=None)
    p.add_argument("--model", default=None)
    p.add_argument("--music", default=None)
    p.add_argument("--music-start", type=float, default=None)
    p.add_argument("--config", default=None, help="JSON config file to start from")
    p.add_argument("--set", action="append", default=[], metavar="KEY=VALUE")
    return p.parse_args(argv)


def build_config(args: argparse.Namespace) -> PipelineConfig:
    if args.config:
        cfg = PipelineConfig.load(Path(args.config))
    elif args.workspace and (Path(args.workspace) / "config.json").exists():
        cfg = PipelineConfig.load(Path(args.workspace) / "config.json")
    else:
        cfg = PipelineConfig()
    if args.source:
        cfg.source = args.source
    if not cfg.source:
        raise SystemExit("give a footage file, or a --workspace that already holds a config.json")
    cfg.workspace = args.workspace or cfg.workspace or f"{Path(cfg.source).with_suffix('')}_edit"
    if args.brief:
        cfg.brief = args.brief
    if args.target_duration is not None:
        cfg.target_duration = args.target_duration
    if args.backend:
        cfg.llm.backend = args.backend
    if args.model:
        cfg.llm.model = args.model
    if args.music:
        cfg.music.path = args.music
    if args.music_start is not None:
        cfg.music.start = args.music_start
    cfg.apply_overrides(args.set)
    return cfg


def main(argv: Optional[List[str]] = None) -> int:
    args = parse_args(argv)
    cfg = build_config(args)
    try:
        from .app import MatchcutApp
    except ImportError as e:  # textual / textual-image missing
        print(f"{INSTALL_HINT}\n({e})", file=sys.stderr)
        return 1
    MatchcutApp(cfg).run()
    return 0


if __name__ == "__main__":  # pragma: no cover
    sys.exit(main())
```

```python
"""UI-side model of a run and of the workspace it reads from."""
from __future__ import annotations

import json
import time
from collections import deque
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Deque, Dict, List, Optional, Tuple

from matchcut.pipeline import events
from matchcut.pipeline.audio import MusicAnalysis
from matchcut.pipeline.config import PipelineConfig
from matchcut.pipeline.media import MediaInfo
from matchcut.pipeline.shots import Shot, load_shots
from matchcut.pipeline.timeline import Decision, Timeline

STAGE_STATES = ("pending", "cached", "running", "done", "waiting", "failed", "stopping")

# USD per million tokens (input, output); an estimate shown as "~$" in the status bar
PRICES: Dict[str, Tuple[float, float]] = {
    "claude-opus-5-5": (4.0, 20.0),
    "claude-sonnet-5-5": (2.0, 10.0),
    "claude-haiku-5-5": (0.10, 0.50),
    "claude-fable-5-1": (10.0, 50.0),
}


@dataclass
class StageStatus:
    name: str
    state: str = "pending"
    seconds: float = 0.0
    path: str = ""
    error: str = ""


@dataclass
class PendingCheckpoint:
    stage: str
    summary: dict


class RunState:
    def __init__(self, cfg: PipelineConfig):
        self.config = cfg
        self.workspace = Path(cfg.workspace)
        self.stages: Dict[str, StageStatus] = {n: StageStatus(n) for n in self.stage_names()}
        self.events: Deque[events.Event] = deque(maxlen=5000)
        self.checkpoint: Optional[PendingCheckpoint] = None
        self.run_status = "idle"
        self.started_at: Optional[float] = None
        self.finished_at: Optional[float] = None
        self.calls = 0
        self.input_tokens = 0
        self.output_tokens = 0
        self.model = cfg.llm.model
        self.last_error = ""
        self.image_mode = ""
        self._cache: Dict[str, Tuple[float, Any]] = {}  # path -> (mtime, parsed)

    # -- stages ----------------------------------------------------------
    def stage_names(self) -> List[str]:
        return ["ingest", "describe", "narrative", "roughcut"] + [f"pass:{p}" for p in self.config.passes] + ["render", "report"]

    def _stage(self, name: str) -> StageStatus:
        if name not in self.stages:
            self.stages[name] = StageStatus(name)
        return self.stages[name]

    # -- events ----------------------------------------------------------
    def apply(self, event: events.Event) -> None:
        self.events.append(event)
        if isinstance(event, events.RunStarted):
            self.stages = {n: StageStatus(n) for n in self.stage_names()}
            self.checkpoint = None
            self.run_status = "running"
            self.started_at = time.time()
            self.finished_at = None
            self.calls = self.input_tokens = self.output_tokens = 0
            self.last_error = ""
        elif isinstance(event, events.StageStarted):
            self._stage(event.stage).state = "running"
            if self.run_status != "stopping":
                self.run_status = "running"
        elif isinstance(event, events.StageCached):
            s = self._stage(event.stage)
            s.state, s.path = "cached", event.path
        elif isinstance(event, events.StageFinished):
            s = self._stage(event.stage)
            s.state, s.seconds, s.path = "done", event.seconds, event.path
            if event.path:
                self.invalidate(event.path)
        elif isinstance(event, events.Checkpoint):
            self._stage(event.stage).state = "waiting"
            self.checkpoint = PendingCheckpoint(event.stage, dict(event.summary))
            self.run_status = "waiting"
        elif isinstance(event, events.ModelCall):
            self.calls += 1
            self.input_tokens += event.input_tokens
            self.output_tokens += event.output_tokens
            self.model = event.model or self.model
        elif isinstance(event, events.RunFinished):
            self.run_status = "finished"
            self.finished_at = time.time()
            self.checkpoint = None
        elif isinstance(event, events.RunFailed):
            self.run_status = "failed"
            self.finished_at = time.time()
            self.last_error = event.error
            self.checkpoint = None
            if event.stage:
                self._stage(event.stage).state = "failed"
                self._stage(event.stage).error = event.error

    def resolve_checkpoint(self) -> None:
        """The UI answered the pending checkpoint."""
        if self.checkpoint is not None:
            s = self._stage(self.checkpoint.stage)
            if s.state == "waiting":
                s.state = "done"
        self.checkpoint = None
        if self.run_status == "waiting":
            self.run_status = "running"

    def mark_stopping(self) -> None:
        self.run_status = "stopping"
        for s in self.stages.values():
            if s.state in ("running", "waiting"):
                s.state = "stopping"

    def elapsed(self) -> float:
        if self.started_at is None:
            return 0.0
        return (self.finished_at or time.time()) - self.started_at

    def cost_estimate(self) -> float:
        inp, out = PRICES.get(self.model, (0.0, 0.0))
        return self.input_tokens / 1e6 * inp + self.output_tokens / 1e6 * out

    # -- workspace readers (cached by mtime) --------------------------------
    def invalidate(self, path: str) -> None:
        self._cache.pop(str(Path(path)), None)

    def _load(self, path: Path, loader):
        key = str(path)
        if not path.exists():
            self._cache.pop(key, None)
            return None
        mtime = path.stat().st_mtime
        cached = self._cache.get(key)
        if cached is not None and cached[0] == mtime:
            return cached[1]
        try:
            value = loader(path)
        except Exception:
            return None
        self._cache[key] = (mtime, value)
        return value

    def media(self) -> Optional[MediaInfo]:
        return self._load(self.workspace / "probe.json", lambda p: MediaInfo.from_dict(json.loads(p.read_text())))

    def shots(self) -> List[Shot]:
        return self._load(self.workspace / "shots.json", load_shots) or []

    def descriptions(self) -> Dict[int, dict]:
        data = self._load(self.workspace / "descriptions.json", lambda p: json.loads(p.read_text()))
        return {int(k): v for k, v in data.items()} if data else {}

    def narrative(self) -> dict:
        return self._load(self.workspace / "narrative.json", lambda p: json.loads(p.read_text())) or {}

    def music(self) -> Optional[MusicAnalysis]:
        if not self.config.music.path:
            return None
        return self._load(self.workspace / "music.json", MusicAnalysis.load)

    def _timeline_path(self, stage: str) -> Optional[Path]:
        if stage == "roughcut":
            return self.workspace / "roughcut.json"
        if stage == "final":
            return self.workspace / "final.json"
        passes_dir = self.workspace / "passes"
        if passes_dir.exists():
            for p in sorted(passes_dir.glob("*.json")):
                if p.stem.split("_", 1)[-1] == stage:
                    return p
        return None

    def timeline_stages(self) -> List[str]:
        out: List[str] = []
        if (self.workspace / "roughcut.json").exists():
            out.append("roughcut")
        passes_dir = self.workspace / "passes"
        if passes_dir.exists():
            out += [p.stem.split("_", 1)[-1] for p in sorted(passes_dir.glob("*.json"))]
        if (self.workspace / "final.json").exists():
            out.append("final")
        return out

    def timeline(self, stage: str) -> Optional[Timeline]:
        path = self._timeline_path(stage)
        return self._load(path, Timeline.load) if path is not None else None

    def decisions_for(self, clip_id: str, stage: str) -> List[Decision]:
        tl = self.timeline(stage)
        if tl is None:
            return []
        return [d for d in tl.history if clip_id in d.clip_ids]
```

```python
"""Runs the pipeline on a worker thread and talks to it through a queue.

Framework-free: the TUI pumps ``drain()`` from its event loop and calls
``answer`` / ``stop`` from the UI thread. The pipeline thread only puts events
on the queue and blocks inside the checkpoint handler.

``interactive=False`` (the default) answers every checkpoint with Continue
immediately, so a run behaves like the CLI; the app passes ``interactive=True``
and answers from the Run view.
"""
from __future__ import annotations

import queue
import threading
from typing import Dict, List, Optional, Tuple

from matchcut.pipeline import events
from matchcut.pipeline.config import PipelineConfig
from matchcut.pipeline.llm import LLMBackend
from matchcut.pipeline.pipeline import Pipeline


class PipelineBridge:
    def __init__(self, cfg: PipelineConfig, backend: Optional[LLMBackend] = None, interactive: bool = False):
        self.cfg = cfg
        self.backend = backend
        self.interactive = interactive
        self.queue: "queue.Queue[events.Event]" = queue.Queue()
        self.cancel = threading.Event()
        self.pending: Optional[Tuple[str, dict]] = None
        self.pipeline: Optional[Pipeline] = None
        self._answer: Optional[events.CheckpointAnswer] = None
        self._answered = threading.Event()
        self._thread: Optional[threading.Thread] = None

    # -- lifecycle ---------------------------------------------------------
    def start(self) -> None:
        if self.is_running():
            raise RuntimeError("a run is already in progress")
        self.cancel.clear()
        self.pending = None
        self.pipeline = Pipeline(self.cfg, on_event=self.queue.put, on_checkpoint=self._checkpoint, cancel=self.cancel)
        if self.backend is not None:
            self.pipeline.llm = self.backend
            self.backend.on_call = self.pipeline._emit
        self._thread = threading.Thread(target=self._run, name="matchcut-pipeline", daemon=True)
        self._thread.start()

    def _run(self) -> None:
        assert self.pipeline is not None
        try:
            self.pipeline.run()
        except Exception:
            # RunFailed was already emitted by Pipeline.run(); the thread just ends
            pass
        finally:
            self.pending = None

    def is_running(self) -> bool:
        return self._thread is not None and self._thread.is_alive()

    def join(self, timeout: float) -> None:
        if self._thread is not None:
            self._thread.join(timeout)

    def drain(self) -> List[events.Event]:
        out: List[events.Event] = []
        while True:
            try:
                out.append(self.queue.get_nowait())
            except queue.Empty:
                return out

    # -- checkpoints (pipeline thread blocks here) ----------------------------
    def _checkpoint(self, stage: str, summary: dict) -> events.CheckpointAnswer:
        if not self.interactive:
            return events.Continue()
        self._answered.clear()
        self._answer = None
        self.pending = (stage, summary)
        self._answered.wait()
        self.pending = None
        return self._answer if self._answer is not None else events.Continue()

    def answer(self, answer: events.CheckpointAnswer) -> bool:
        """Answer the pending checkpoint from the UI thread. Returns False when none is pending."""
        if self.pending is None:
            return False
        if isinstance(answer, events.Redo):
            self.cfg.save(self.cfg.workspace_path / "config.json")  # config edits made while paused persist
        self._answer = answer
        self._answered.set()
        return True

    def stop(self) -> None:
        """Cancel at the next boundary; abort immediately if a checkpoint is pending."""
        self.cancel.set()
        if self.pending is not None:
            self.answer(events.Abort())

    # -- live context updates ------------------------------------------------
    def set_descriptions(self, descriptions: Dict[int, dict]) -> None:
        """Make edited shot descriptions visible to the stages that run after this point."""
        if self.pipeline is not None and self.pipeline._ctx is not None:
            self.pipeline._ctx.descriptions = dict(descriptions)
```

```python
"""Image loading, terminal image protocol selection, external viewer."""
from __future__ import annotations

import os
import shutil
import subprocess
import sys
from pathlib import Path
from typing import Dict, Optional, Tuple

from PIL import Image as PILImage

_cache: Dict[Tuple[str, float, int], PILImage.Image] = {}


def clear_cache() -> None:
    _cache.clear()


def load_image(path: Path, max_width: int = 640) -> Optional[PILImage.Image]:
    """RGB image scaled to at most ``max_width`` wide, cached by path + mtime. None when unavailable."""
    path = Path(path)
    if not path.exists():
        return None
    try:
        mtime = path.stat().st_mtime
        key = (str(path), mtime, max_width)
        if key in _cache:
            return _cache[key]
        img = PILImage.open(path).convert("RGB")
        if img.width > max_width:
            img = img.resize((max_width, max(1, int(img.height * max_width / img.width))), PILImage.LANCZOS)
        _cache[key] = img
        return img
    except Exception:
        return None


def widget_class(headless: bool) -> type:
    """textual-image widget to use: half-block under tests or when forced, else auto-detect."""
    from textual_image.widget import HalfcellImage, Image

    if headless or os.environ.get("MATCHCUT_TUI_IMAGES", "").lower() == "halfcell":
        return HalfcellImage
    return Image


def protocol_label(cls: type) -> str:
    name = cls.__name__.lower()
    if "halfcell" in name:
        return "half-block"
    if "unicode" in name:
        return "unicode blocks"
    if "sixel" in name:
        return "sixel"
    if "tgp" in name:
        return "kitty graphics"
    return "auto (kitty/iterm2/sixel)"


def open_externally(path: Path) -> bool:
    """Open a file in the system viewer. Returns False when no opener is available."""
    opener = "open" if sys.platform == "darwin" else "xdg-open"
    if shutil.which(opener) is None:
        return False
    subprocess.Popen([opener, str(path)], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
    return True
```

```python
"""A one-line timeline track: clips as coloured spans, transitions, locks, beat grid."""
from __future__ import annotations

from typing import List, Optional

from rich.text import Text
from textual.widgets import Static

from matchcut.pipeline.timeline import Timeline

PALETTE = ["on dark_blue", "on dark_green", "on dark_magenta", "on dark_cyan", "on dark_orange3", "on grey37"]
GLYPHS = {"cut": "|", "dissolve": "~", "dip_to_black": "#"}


def render_track(tl: Timeline, width: int, selected: int, beats: Optional[List[float]] = None, music_start: float = 0.0) -> Text:
    text = Text()
    if not tl.clips:
        text.append("(empty timeline)", style="dim")
        return text
    total = max(tl.duration, 1e-6)
    beat_ids = []
    for c in tl.clips:
        if c.beat_id not in beat_ids:
            beat_ids.append(c.beat_id)
    usable = max(width - len(tl.clips), 10)
    for i, c in enumerate(tl.clips):
        if i > 0:
            prev = tl.clips[i - 1]
            locked = prev.locked_out and c.locked_in
            glyph = "L" if locked else GLYPHS.get(c.transition_in.kind, "|")
            text.append(glyph, style="bold white" if locked else "white")
        span = max(1, int(round(c.duration / total * usable)))
        label = f"{c.id[-3:].lstrip('0') or '0'}:s{c.shot_index}"[:span].ljust(span)
        style = PALETTE[beat_ids.index(c.beat_id) % len(PALETTE)]
        if i == selected:
            style += " reverse bold"
        text.append(label, style=style)
    if beats is not None:
        text.append("\n")
        grid = [" "] * width
        for b in beats:
            t = b - music_start
            if 0 <= t <= total:
                col = min(width - 1, int(t / total * width))
                grid[col] = "."
        text.append("".join(grid), style="dim")
    return text


class TimelineTrack(Static):
    DEFAULT_CSS = "TimelineTrack { height: 2; }"

    def __init__(self, **kwargs) -> None:
        super().__init__("", **kwargs)
        self.timeline: Optional[Timeline] = None
        self.beats: Optional[List[float]] = None
        self.music_start = 0.0
        self.selected = 0

    def set_timeline(self, tl: Optional[Timeline], beats: Optional[List[float]] = None, music_start: float = 0.0) -> None:
        self.timeline, self.beats, self.music_start = tl, beats, music_start
        self.selected = min(self.selected, max(0, (len(tl.clips) - 1) if tl else 0))
        if tl is None:
            self.selected = 0
        self._redraw()

    def select_next(self) -> None:
        if self.timeline and self.selected < len(self.timeline.clips) - 1:
            self.selected += 1
            self._redraw()

    def select_prev(self) -> None:
        if self.selected > 0:
            self.selected -= 1
            self._redraw()

    def _redraw(self) -> None:
        width = max(20, self.size.width or 80)
        if self.timeline is None:
            self.update(Text("(no timeline yet)", style="dim"))
            return
        self.update(render_track(self.timeline, width, self.selected, self.beats, self.music_start))

    def on_resize(self) -> None:
        self._redraw()
```

```python
import json
from typing import Optional

from rich.text import Text
from textual.app import ComposeResult
from textual.binding import Binding
from textual.containers import Horizontal, Vertical
from textual.widgets import Input, RichLog, Static

from matchcut.pipeline import events
from ..state import RunState
from ..widgets.ladder import StageLadder

FILTERS = ("all", "decisions", "model", "log")


class RunView(Vertical):
    BINDINGS = [
        Binding("c", "cp_continue", "Continue", show=False),
        Binding("r", "cp_redo", "Redo with note", show=False),
        Binding("a", "cp_abort", "Abort", show=False),
        Binding("f", "cycle_filter", "Filter log", show=False),
    ]

    def __init__(self, **kwargs) -> None:
        super().__init__(**kwargs)
        self._seen = 0
        self._filter = 0

    def compose(self) -> ComposeResult:
        with Horizontal(id="run-top"):
            yield StageLadder(id="ladder")
            yield RichLog(id="log", highlight=False, markup=False, wrap=True)
        with Vertical(id="checkpoint"):
            yield Static("", id="checkpoint-summary")
            yield Input(placeholder="director's note for a redo (optional)", id="note")
            yield Static("[c] continue   [r] redo with note (type note, Enter, then r)   [a] abort", id="checkpoint-hint")

    def on_mount(self) -> None:
        self.query_one("#checkpoint").display = False

    # -- rendering -----------------------------------------------------------
    def pending_text(self) -> str:
        return str(self.query_one("#checkpoint-summary", Static).renderable)

    def refresh_from_state(self, state: RunState) -> None:
        self.query_one("#ladder", StageLadder).update_stages(state.stages)
        log = self.query_one("#log", RichLog)
        events_list = list(state.events)
        if len(events_list) < self._seen:  # a new run reset the deque
            log.clear()
            self._seen = 0
        for e in events_list[self._seen :]:
            line = self._format(e)
            if line is not None:
                log.write(line)
        self._seen = len(events_list)
        panel = self.query_one("#checkpoint")
        if state.checkpoint is not None:
            cp = state.checkpoint
            panel.display = True
            self.query_one("#checkpoint-summary", Static).update(
                Text.assemble((f"Checkpoint after {cp.stage}", "bold magenta"), "\n", json.dumps(cp.summary, indent=1)[:1200])
            )
        else:
            panel.display = False

    def _format(self, e: events.Event) -> Optional[Text]:
        f = FILTERS[self._filter]
        if isinstance(e, events.Decision):
            if f not in ("all", "decisions"):
                return None
            score = f" [{e.score:.2f}]" if e.score is not None else ""
            return Text.assemble((f"{e.pass_name}:{e.action}", "cyan"), f" {', '.join(e.clip_ids[:4])}{score} {e.detail}")
        if isinstance(e, events.ModelCall):
            if f not in ("all", "model"):
                return None
            return Text.assemble(("model ", "yellow"), f"{e.name} images={e.images} in={e.input_tokens} out={e.output_tokens} {e.seconds:.1f}s")
        if isinstance(e, events.Log):
            if f not in ("all", "log"):
                return None
            return Text(e.message, style="dim" if e.level == "info" else "red")
        if isinstance(e, (events.StageStarted, events.StageFinished, events.StageCached)):
            if f != "all":
                return None
            return Text(f"{type(e).__name__.replace('Stage', '').lower()} {e.stage}", style="green")
        if isinstance(e, events.RunFailed):
            return Text.assemble(("FAILED ", "bold red"), f"{e.stage}: {e.error}\n{e.traceback[-800:]}")
        if isinstance(e, events.RunFinished):
            return Text(f"run finished in {e.seconds:.1f}s -> {e.final_path}", style="bold green")
        if isinstance(e, events.Checkpoint):
            return Text(f"checkpoint {e.stage}", style="magenta")
        return None

    # -- actions ------------------------------------------------------------------
    def _answer(self, answer: events.CheckpointAnswer) -> None:
        app = self.app
        if getattr(app, "bridge", None) is None or app.state.checkpoint is None:
            return
        if app.bridge.answer(answer):
            app.state.resolve_checkpoint()
            self.query_one("#note", Input).value = ""
            app.refresh_views()

    def action_cp_continue(self) -> None:
        self._answer(events.Continue())

    def action_cp_redo(self) -> None:
        self._answer(events.Redo(self.query_one("#note", Input).value.strip()))

    def action_cp_abort(self) -> None:
        self._answer(events.Abort())

        self._filter = (self._filter + 1) % len(FILTERS)
        self.query_one("#log", RichLog).clear()
        self._seen = 0
        self.refresh_from_state(self.app.state)
        self.app.notify(f"log filter: {FILTERS[self._filter]}")
```

```python
"""The control-room application."""
from __future__ import annotations

from typing import Callable, Optional

from textual.app import App, ComposeResult
from textual.binding import Binding
from textual.screen import ModalScreen
from textual.widgets import Footer, Static, TabbedContent, TabPane

from matchcut.pipeline.config import PipelineConfig
from .bridge import PipelineBridge
from .state import RunState
from .views.run import RunView

HELP_TEXT = """Control room keys

 1-5   Run / Shots / Story / Cut / Config        R  run or resume        S  stop
 c/r/a continue / redo with note / abort a checkpoint (Run view)
 f     cycle the log filter (Run view)           o  open the current image or render externally
 u     toggle a shot's usable flag (Shots)       [ ]  step through passes (Cut)    ←/→ select a clip (Cut)
 Enter edit a config value (Config)              ?  this help      Esc  close      q  quit

Press Escape to close."""


class HelpScreen(ModalScreen):
    BINDINGS = [Binding("escape", "dismiss", "Close")]

    def compose(self) -> ComposeResult:
        yield Static(HELP_TEXT, id="help")


class MatchcutApp(App):
    CSS_PATH = "styles.tcss"
    TITLE = "matchcut control room"
    BINDINGS = [
        Binding("1", "show_tab('tab-run')", "Run"),
        Binding("2", "show_tab('tab-shots')", "Shots"),
        Binding("3", "show_tab('tab-story')", "Story"),
        Binding("4", "show_tab('tab-cut')", "Cut"),
        Binding("5", "show_tab('tab-config')", "Config"),
        Binding("R", "run", "Run"),
        Binding("S", "stop", "Stop"),
        Binding("o", "open", "Open"),
        Binding("question_mark", "help", "Help"),
        Binding("q", "quit", "Quit"),
    ]

    def __init__(self, cfg: PipelineConfig, bridge_factory: Optional[Callable[[PipelineConfig], PipelineBridge]] = None) -> None:
        super().__init__()
        self.state = RunState(cfg)
        self.bridge: Optional[PipelineBridge] = None
        self._bridge_factory = bridge_factory or (lambda c: PipelineBridge(c, interactive=True))
        self._quit_armed = False

    # -- layout --------------------------------------------------------------
    def compose(self) -> ComposeResult:
        yield Static("", id="status")
        with TabbedContent(initial="tab-run"):
            with TabPane("1 Run", id="tab-run"):
                yield RunView(id="run-view")
            with TabPane("2 Shots", id="tab-shots"):
                yield Static("shots view (next task)", id="shots-placeholder")
            with TabPane("3 Story", id="tab-story"):
                yield Static("story view (next task)", id="story-placeholder")
            with TabPane("4 Cut", id="tab-cut"):
                yield Static("cut view (next task)", id="cut-placeholder")
            with TabPane("5 Config", id="tab-config"):
                yield Static("config view (next task)", id="config-placeholder")
        yield Footer()

    def on_mount(self) -> None:
        self.set_interval(0.05, self._pump)
        self.refresh_views()

    # -- event pump -------------------------------------------------------------
    def _pump(self) -> None:
        changed = False
        if self.bridge is not None:
            for e in self.bridge.drain():
                self.state.apply(e)
                changed = True
        self._update_status()
        if changed:
            self.refresh_views()

    def refresh_views(self) -> None:
        for view in self.query("RunView, ShotsView, StoryView, CutView, ConfigView"):
            view.refresh_from_state(self.state)
        self._update_status()

    def _update_status(self) -> None:
        st = self.state
        source = st.config.source.rsplit("/", 1)[-1]
        running = st.checkpoint.stage if st.checkpoint else next((n for n, s in st.stages.items() if s.state in ("running", "stopping")), "-")
        text = (
            f"{source}  |  {st.run_status}  |  stage {running}  |  {st.elapsed():6.1f}s  |  "
            f"{st.calls} calls  {st.input_tokens}/{st.output_tokens} tok  ~${st.cost_estimate():.3f}"
        )
        if st.image_mode:
            text += f"  |  images: {st.image_mode}"
        self.query_one("#status", Static).update(text)

    # -- actions ----------------------------------------------------------------
    def action_show_tab(self, tab: str) -> None:

            self.notify("a run is already in progress", severity="warning")
            return
        self.bridge = self._bridge_factory(self.state.config)
        self.bridge.start()
        self.action_show_tab("tab-run")

    def action_stop(self) -> None:
        if self.bridge is None or not self.bridge.is_running():
            self.notify("nothing is running")
            return
        self.state.mark_stopping()
        self.bridge.stop()
        self.refresh_views()

    def action_open(self) -> None:  # Task 8 fills this in
        self.notify("nothing to open yet")

    def action_help(self) -> None:
        self.push_screen(HelpScreen(name="help"))

    def action_quit(self) -> None:
        if self.bridge is not None and self.bridge.is_running() and not self._quit_armed:
            self._quit_armed = True
            self.notify("a run is active: press q again to quit anyway", severity="warning")
            return
        if self.bridge is not None:
            self.bridge.stop()
        self.exit()
```

```python
"""Shots view: the catalog, three keyframes and the model's description."""
from __future__ import annotations

import json
from pathlib import Path
from typing import Dict, Optional

from rich.text import Text
from textual.app import ComposeResult
from textual.binding import Binding
from textual.containers import Horizontal, Vertical
from textual.widgets import DataTable, Static

from matchcut.pipeline.sampling import FrameCache, shot_sample_times
from .. import images
from ..state import RunState
from ..widgets.frame import Frame


class ShotsView(Horizontal):
    BINDINGS = [Binding("u", "toggle_usable", "Toggle usable", show=False)]

    def __init__(self, **kwargs) -> None:
        super().__init__(**kwargs)
        self._state: Optional[RunState] = None
        self._loaded_for: Optional[int] = None

    def compose(self) -> ComposeResult:
        yield DataTable(id="shots-table")
        with Vertical(id="shot-detail"):
            with Horizontal(id="shot-frames"):
                yield Frame(id="shot-head", caption="head")
                yield Frame(id="shot-mid", caption="middle")
                yield Frame(id="shot-tail", caption="tail")
            yield Static("", id="shot-desc")

    def on_mount(self) -> None:
        table = self.query_one("#shots-table", DataTable)
        table.cursor_type = "row"
        table.zebra_stripes = True
        table.add_columns("#", "Start", "End", "Dur", "Subject", "Size", "Move", "Q", "Use")

    # -- data --------------------------------------------------------------
    def refresh_from_state(self, state: RunState) -> None:
        self._state = state
        table = self.query_one("#shots-table", DataTable)
        cursor = table.cursor_row
        table.clear()
        descs = state.descriptions()
        for shot in state.shots():
            d = descs.get(shot.index, {})
            table.add_row(
                str(shot.index),
                f"{shot.start:.2f}",
                f"{shot.end:.2f}",
                f"{shot.duration:.1f}",
                str(d.get("subject", ""))[:28],
                str(d.get("shot_size", "")),
                str(d.get("camera_movement", "")),
                f"{float(d.get('quality', 0.0)):.2f}" if d else "",
                Text("yes" if d.get("usable", True) else "no", style="green" if d.get("usable", True) else "red"),
                key=str(shot.index),
            )
        if table.row_count:
            table.move_cursor(row=min(cursor, table.row_count - 1))
            self._show(self.current_shot_index())
        else:
            self.query_one("#shot-desc", Static).update("(no shots yet: run the pipeline)")

    def current_shot_index(self) -> Optional[int]:
        table = self.query_one("#shots-table", DataTable)
        if not table.row_count:
            return None
        try:
            key = table.coordinate_to_cell_key(table.cursor_coordinate).row_key
            return int(str(key.value))
        except Exception:
            return None

    def on_data_table_row_highlighted(self, event: DataTable.RowHighlighted) -> None:
        self._show(int(str(event.row_key.value)) if event.row_key is not None else None)

    def _show(self, index: Optional[int]) -> None:
        if self._state is None or index is None:
            return
        shots = {s.index: s for s in self._state.shots()}
        shot = shots.get(index)
        media = self._state.media()
        if shot is None or media is None:
            return
        self._loaded_for = index
        cache = FrameCache(media.path, self._state.workspace / "frames", self._state.config.sampling)
        times = shot_sample_times(shot, 3)
        for fid, t in zip(("#shot-head", "#shot-mid", "#shot-tail"), times):
            frame = self.query_one(fid, Frame)
            try:
                img = cache.frame(t)
            except Exception:
                img = None
            frame.show(img, caption=f"{t:.2f}s")
            if frame.image_mode:
                self._state.image_mode = frame.image_mode
        d = self._state.descriptions().get(index, {})
        lines = [f"Shot {index}  {shot.start:.2f}-{shot.end:.2f}s ({shot.duration:.1f}s)"]
        if d:
            lines.append(d.get("description", ""))
            lines.append(f"subject: {d.get('subject', '')}   setting: {d.get('setting', '')}   mood: {d.get('mood', '')}")
            lines.append(f"size: {d.get('shot_size', '')}   camera: {d.get('camera_movement', '')}   motion: {d.get('subject_motion', '')}   shapes: {d.get('dominant_shapes', '')}")
            lines.append(f"key action: {d.get('key_action', '')}   quality: {d.get('quality', '')}   usable: {d.get('usable', True)}   tags: {', '.join(d.get('tags', []))}")
        else:
            lines.append("(no description yet)")
        self.query_one("#shot-desc", Static).update("\n".join(lines))

    # -- actions ---------------------------------------------------------------
    def action_toggle_usable(self) -> None:
        index = self.current_shot_index()
        if self._state is None or index is None:
            return
        path = self._state.workspace / "descriptions.json"
        if not path.exists():
            self.app.notify("no descriptions yet", severity="warning")
            return
        data: Dict[str, dict] = json.loads(path.read_text())
        entry = data.get(str(index))
        if entry is None:
            return
        entry["usable"] = not entry.get("usable", True)
        path.write_text(json.dumps(data, indent=2))
        self._state.invalidate(str(path))
        bridge = getattr(self.app, "bridge", None)
        if bridge is not None:
            bridge.set_descriptions({int(k): v for k, v in data.items()})
        self.refresh_from_state(self._state)
        self.app.notify(f"shot {index} usable: {entry['usable']}")
```

```python
from typing import List, Optional

class StoryView(VerticalScroll):

            )
        )

            text = Text.assemble(
                (f"{b.get('id', '')}  {b.get('title', '')}", "bold cyan"),

        for i in range(1, len(tl.clips)):
```

```python
"""Cut view: the timeline track, clip detail, and a stepper through the passes."""
from __future__ import annotations

from typing import List, Optional

from rich.text import Text
from textual.app import ComposeResult
from textual.binding import Binding
from textual.containers import Horizontal, Vertical
from textual.widgets import Static

from matchcut.pipeline.sampling import FrameCache
from ..state import RunState
from ..widgets.frame import Frame
from ..widgets.timeline import TimelineTrack


class CutView(Vertical):
    BINDINGS = [
        Binding("left", "prev_clip", "Previous clip", show=False),
        Binding("right", "next_clip", "Next clip", show=False),
        Binding("left_square_bracket", "prev_stage", "Earlier pass", show=False),
        Binding("right_square_bracket", "next_stage", "Later pass", show=False),
    ]

    def __init__(self, **kwargs) -> None:
        super().__init__(**kwargs)
        self._state: Optional[RunState] = None
        self.stages: List[str] = []
        self.stage_index = -1  # -1 means "latest"

    def compose(self) -> ComposeResult:
        yield Static("", id="cut-header")
        yield TimelineTrack(id="track")
        with Horizontal(id="clip-row"):
            yield Frame(id="clip-frame", caption="first frame")
            yield Static("", id="clip-detail")

    def current_stage(self) -> Optional[str]:
        if not self.stages:
            return None
        idx = self.stage_index if self.stage_index >= 0 else len(self.stages) - 1
        return self.stages[min(idx, len(self.stages) - 1)]

    def refresh_from_state(self, state: RunState) -> None:
        self._state = state
        self.stages = state.timeline_stages()
        if self.stage_index >= len(self.stages):
            self.stage_index = -1
        stage = self.current_stage()
        track = self.query_one("#track", TimelineTrack)
        header = self.query_one("#cut-header", Static)
        if stage is None:
            header.update("(no timeline yet: run the pipeline)")
            track.set_timeline(None)
            self.query_one("#clip-detail", Static).update("")
            self.query_one("#clip-frame", Frame).show(None)
            return
        tl = state.timeline(stage)
        music = state.music()
        beats = [float(b) for b in music.beats] if music is not None else None
        track.set_timeline(tl, beats, state.config.music.start)
        pos = self.stages.index(stage) + 1
        header.update(Text.assemble(("stage ", "dim"), (stage, "bold"), (f"  ({pos}/{len(self.stages)})  ", "dim"), f"{len(tl.clips) if tl else 0} clips, {tl.duration if tl else 0:.1f}s   [ ] step passes   ←/→ select clip"))
        self._show_clip()

    def _show_clip(self) -> None:
        if self._state is None:
            return
        track = self.query_one("#track", TimelineTrack)
        tl = track.timeline
        detail = self.query_one("#clip-detail", Static)
        frame = self.query_one("#clip-frame", Frame)
        if tl is None or not tl.clips:
            detail.update("")
            frame.show(None)
            return
        i = track.selected
        c = tl.clips[i]
        stage = self.current_stage() or "final"
        decisions = self._state.decisions_for(c.id, stage)
        lines = [
            f"{c.id}  shot {c.shot_index}  beat {c.beat_id}",
            f"source {c.source_in:.2f}-{c.source_out:.2f}s  ({c.duration:.2f}s)  record in {tl.record_start(i):.2f}s",
            f"transition in: {c.transition_in.kind} {c.transition_in.duration:.2f}s   locked: {'in ' if c.locked_in else ''}{'out' if c.locked_out else ''}".rstrip(),
            f"tags: {', '.join(c.tags) or '-'}   purpose: {c.purpose or '-'}",
            "",
            f"decisions ({len(decisions)}):",
        ] + [f"  {d.pass_name}:{d.action}  {d.detail}" for d in decisions[-12:]]
        detail.update("\n".join(lines))
        media = self._state.media()
        if media is None:
            frame.show(None)
            return
        cache = FrameCache(media.path, self._state.workspace / "frames", self._state.config.sampling)
        try:
            img = cache.frame(c.source_in)
        except Exception:
            img = None
        frame.show(img, caption=f"{c.id} @ {c.source_in:.2f}s")
        if frame.image_mode:
            self._state.image_mode = frame.image_mode

    # -- actions ------------------------------------------------------------------
    def action_prev_clip(self) -> None:
        self.query_one("#track", TimelineTrack).select_prev()
        self._show_clip()

    def action_next_clip(self) -> None:
        self.query_one("#track", TimelineTrack).select_next()
        self._show_clip()

    def action_prev_stage(self) -> None:
        if not self.stages:
            return
        current = self.stages.index(self.current_stage())
        self.stage_index = max(0, current - 1)
        self.refresh_from_state(self._state)

    def action_next_stage(self) -> None:
        if not self.stages:
            return
        current = self.stages.index(self.current_stage())
        self.stage_index = min(len(self.stages) - 1, current + 1)
        if self.stage_index == len(self.stages) - 1:
            self.stage_index = -1  # follow the latest again
        self.refresh_from_state(self._state)
```

```python
"""Config view: the live PipelineConfig as an editable tree."""
from __future__ import annotations

import dataclasses
from typing import Any, Optional, Tuple

from textual.app import ComposeResult
from textual.containers import Vertical
from textual.widgets import Input, Static, Tree

from matchcut.pipeline.config import PipelineConfig
from ..state import RunState

TOP_LEVEL_FIELDS = ("source", "workspace", "brief", "target_duration", "passes", "force", "seed")


def parse_value(current: Any, text: str) -> Any:
    text = text.strip()
    if isinstance(current, bool):
        if text.lower() in ("true", "yes", "1", "on"):
            return True
        if text.lower() in ("false", "no", "0", "off"):
            return False
        raise ValueError(f"not a boolean: {text!r}")
    if isinstance(current, int):
        return int(text)
    if isinstance(current, float):
        return float(text)
    if isinstance(current, tuple):
        return tuple(p.strip() for p in text.split(",") if p.strip())
    if current is None or isinstance(current, str):
        return text or None
    raise ValueError(f"cannot edit values of type {type(current).__name__}")


def set_value(cfg: PipelineConfig, section: Optional[str], field: str, value: Any) -> None:
    target = cfg if section is None else getattr(cfg, section)
    setattr(target, field, value)


class ConfigView(Vertical):
    def __init__(self, **kwargs) -> None:
        super().__init__(**kwargs)
        self._state: Optional[RunState] = None
        self._editing: Optional[Tuple[Optional[str], str]] = None

    def compose(self) -> ComposeResult:
        yield Static("Enter: edit the highlighted value.  Changes apply to the next run or redo (and are saved then).", id="config-hint")
        yield Tree("config", id="config-tree")
        yield Input(placeholder="new value, then Enter (Esc cancels)", id="config-edit")

    def on_mount(self) -> None:
        self.query_one("#config-edit").display = False

    # -- tree ------------------------------------------------------------------
    def refresh_from_state(self, state: RunState) -> None:
        self._state = state
        tree = self.query_one("#config-tree", Tree)
        tree.clear()
        cfg = state.config
        for name in TOP_LEVEL_FIELDS:
            tree.root.add_leaf(self._label(name, getattr(cfg, name)), data=(None, name))
        for f in dataclasses.fields(cfg):
            value = getattr(cfg, f.name)
            if dataclasses.is_dataclass(value):
                node = tree.root.add(f.name, data=None)
                for sf in dataclasses.fields(value):
                    sub = getattr(value, sf.name)
                    if isinstance(sub, dict):
                        continue  # pace_targets etc. are edited through --set
                    node.add_leaf(self._label(sf.name, sub), data=(f.name, sf.name))
        tree.root.expand()

    @staticmethod
    def _label(name: str, value: Any) -> str:
        shown = ", ".join(value) if isinstance(value, tuple) else repr(value) if isinstance(value, str) else str(value)
        return f"{name} = {shown}"

    def on_tree_node_selected(self, event: Tree.NodeSelected) -> None:
        if event.node.data is None or self._state is None:
            return
        section, field = event.node.data
        self._editing = (section, field)
        current = getattr(self._state.config if section is None else getattr(self._state.config, section), field)
        edit = self.query_one("#config-edit", Input)
        edit.value = "" if current is None else (", ".join(current) if isinstance(current, tuple) else str(current))
        edit.placeholder = f"{section + '.' if section else ''}{field} ({type(current).__name__}); Enter to apply, Esc to cancel"
        edit.display = True
        edit.focus()

    def on_input_submitted(self, event: Input.Submitted) -> None:
        if event.input.id != "config-edit" or self._editing is None or self._state is None:
            return
        section, field = self._editing
        cfg = self._state.config
        current = getattr(cfg if section is None else getattr(cfg, section), field)
        try:
            value = parse_value(current, event.value)
        except ValueError as e:
            self.app.notify(str(e), severity="error")
            return
        set_value(cfg, section, field, value)
        self._editing = None
        event.input.display = False
        self.refresh_from_state(self._state)
        self.query_one("#config-tree", Tree).focus()
        self.app.notify(f"{section + '.' if section else ''}{field} = {value!r} (applies to the next run or redo)")

    def on_key(self, event) -> None:
        if event.key == "escape" and self._editing is not None:
            self._editing = None
            self.query_one("#config-edit", Input).display = False
            self.query_one("#config-tree", Tree).focus()
            event.stop()
```

```markdown
# Control-room TUI

`python -m matchcut.tui footage.mp4 [-w workspace] [-b brief] [-t seconds] [--music track.mp3] [--backend mock]`

A terminal app that drives and watches pipeline runs and inspects the
workspace they produce. Install with `pip install -r requirements-tui.txt`
on top of the pipeline requirements. Open an existing workspace read-only
with `python -m matchcut.tui -w footage_edit`.

## Views

| Key | View | What it shows |
|---|---|---|
| `1` | Run | the stage ladder (pending / cached / running / done / waiting / failed), the live log of events and decisions (`f` cycles the filter), and the checkpoint panel |
| `2` | Shots | the shot catalog; selecting a row shows head / middle / tail frames and Claude's description; `u` toggles the shot's usable flag (written to `descriptions.json` and seen by a redo in the same run) |
| `3` | Story | logline, theme, beats as cards; with music, the energy curve with beat-change markers |
| `4` | Cut | the timeline as coloured spans by beat with transition glyphs (`\|` cut, `~` dissolve, `#` dip, `L` locked match cut) and the beat grid; `←`/`→` select a clip, `[`/`]` step through the rough cut and each pass |
| `5` | Config | the live config as a tree; Enter edits a value, which applies to the next run or redo |

Global keys: `R` run, `S` stop (aborts a pending checkpoint), `o` open the
current image or render in the system viewer, `?` help, `q` quit (twice while
a run is active).

## Checkpoints

A run pauses after describe, narrative, rough cut and every pass. The Run view
shows the stage's summary and three choices: `c` continue, `r` redo that stage
with the note typed in the field (type the note, press Enter to leave the
field, then `r`), `a` abort. A redo on describe, narrative or rough cut clears
the downstream caches and re-runs with the note added to the prompt as a
director's note; a redo on a deterministic pass only matters together with a
config change. Config edits made while paused are saved on the redo.

## Images

Frames render with the terminal's image protocol (Kitty, iTerm2, Sixel via
textual-image) and fall back to half-block mosaics elsewhere; the footer notice
says which mode is active. Set `MATCHCUT_TUI_IMAGES=halfcell` to force the
fallback.

## How it fits together

`matchcut/tui/bridge.py` runs `Pipeline.run()` on a thread and forwards its
events through a queue; the app applies them to `RunState` 20 times a second
and the views redraw from it. Checkpoints block the pipeline thread until the
Run view answers. Nothing in `matchcut/pipeline/` imports the TUI.
```
