# Interchange fidelity report

Each export was read back with matchcut's own reader and compared with the stage it was written from. **Preserved** items were compared and match. **Approximated** items carry a documented difference. **Lost** items cannot be carried by that format. **Errors** are differences nothing explains; any error fails the export. None of these formats is a complete copy of a matchcut cut.
